# 📦 Inventory Management System

A web-based Inventory Management System developed using **C# and ASP.NET Core MVC** to manage products, categories, suppliers, and inventory stock.

## 🚀 Features

* **Product Management:** Add, edit, view, and delete products.
* **Category Management:** Organize products into categories.
* **Supplier Management:** Manage supplier information.
* **Product Search:** Search for products easily.
* **Stock Management:** Track stock quantities and manage stock in/out operations.
* **Low Stock Alerts:** Identify products with low stock.
* **Dashboard:** Display inventory statistics and key metrics.

## 🛠️ Technologies Used

* C#
* ASP.NET Core MVC
* Entity Framework Core
* Microsoft SQL Server
* HTML5
* CSS3
* JavaScript
* Bootstrap

## ⚙️ Getting Started

### Prerequisites

* Visual Studio
* .NET SDK compatible with the project
* Microsoft SQL Server

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/BigCode17/Inventory-Management-System.git
   ```

2. Open the project in Visual Studio.

3. Configure the SQL Server connection string in `appsettings.json`.

4. Apply the Entity Framework Core migrations if they are included in the repository.

5. Run the application.
